# Food Junction - Helly & Chilly Cafe

A responsive website for **Helly and Chilly Cafe** (Mehsana's Best Food Junction).

## Features
- Modern, vibrant design (Fredoka One & Poppins typography)
- Featured food menu (Burgers, Thick Shakes, Cheesy Pizzas, Loaded Fries)
- Special combo offers & discounts
- Customer reviews & ratings
- Order & visit section with location details

## How to Run
Open `Food Junction!.html` or `index.html` directly in any web browser.
